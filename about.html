Campus Events and Navigation System

Helping students discover events and navigate campus with ease.

Project Overview

The Campus Events and Navigation System is a web-based application designed to improve communication and engagement within a university campus. The system provides students with easy access to information about upcoming events while helping them locate venues and important campus facilities.

Many students miss valuable opportunities because event information is scattered across different platforms. In addition, new students and visitors often struggle to find event locations. This project addresses these challenges by combining event management and navigation features in a single platform.

By using this system, students can stay informed, participate in campus activities, and navigate the campus environment more efficiently.

System Features

Event Discovery

Browse upcoming campus events and discover activities based on interests and categories.

Event Search

Quickly find events using keywords, dates, or categories through a simple search interface.

Interested Events

Save and manage a personalized list of events that users plan to attend.

Reminder Simulation

Demonstrates reminder functionality through notifications or JavaScript alert messages.

Campus Navigation

Helps users locate event venues, lecture halls, offices, and other important campus locations.

  • CSS3: Handles styling and responsive design.
  • JavaScript: Adds interactive functionality.
  • JSON: Stores event and location data.
  • GitHub Pages: Hosts and deploys the project online.

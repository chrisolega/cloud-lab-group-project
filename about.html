Project Overview

The Campus Events and Navigation System is a web-based application designed to improve communication and engagement within a university campus. The system provides students with easy access to information about upcoming events while helping them locate venues and important campus facilities.

Many students miss valuable opportunities because event information is scattered across different platforms. In addition, new students and visitors often struggle to find event locations. This project addresses these challenges by combining event management and navigation features in a single platform.

By using this system, students can stay informed, participate in campus activities, and navigate the campus environment more efficiently.
